STUDENT_INFO-HUB is a student management system developed to maintain and organize student records efficiently. The project provides a secure login system with a maximum of three authentication attempts using predefined ID and password verification. After successful login, the system displays a menu-driven interface that allows the user to perform various operations such as viewing student records, adding new student details, deleting existing records, and exiting the program.
The application uses file handling concepts to store and manage student data based on student year, branch, and section. Separate functions are created for each operation and are called using a switch-case structure for better modularity and readability. The view option enables searching student details through branch, section and year inputs also displays the required record, while the add option creates and stores student information in appropriate files. The delete option searches records using student ID and removes the selected data.
This project helps in simplifying student data management, reducing manual effort, improving accuracy, and providing organized access to student information through a user-friendly interface.
