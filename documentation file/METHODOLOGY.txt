The methodology of the STUDENT_INFO-HUB project is designed to manage student information systematically using file handling and menu-driven operations. The working process of the system is explained below:
The system starts by initializing the login attempt counter and storing the original ID and password.
The user is asked to enter the login credentials. The entered ID and password are verified with the stored credentials.
If the credentials are incorrect, the user is allowed a maximum of three attempts. If all attempts fail, the system terminates the login process.
After successful authentication, the main menu is displayed with different options such as View, Add, Delete, and Exit.
The selected option is processed using separate functions through a switch-case structure for better organization and modular programming.
In the View operation, the system opens the student records file, displays the students list through branch, section and year.
In the Add operation, a new file or record is created based on the student’s year, branch, and section, and the entered data is stored permanently.
In the Delete operation, the system searches the student record using Student ID and removes the corresponding data from the file.
The Exit option terminates the program safely using the exit function.
The entire system is implemented to ensure efficient student record management, easy data retrieval, reduced manual work, and secure access control.
